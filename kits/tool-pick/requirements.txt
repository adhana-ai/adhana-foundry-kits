# The corpus generator writes SQLite with the standard library's own sqlite3, the six policy notes
# are plain text, the keyword floor is `re`, the arithmetic tool is a guarded expression evaluator
# and the HTTP client is urllib. All of that ships with Python, so the fork test is `git clone`
# then:
#
#     python3 tools/build_corpus.py     # the corpus, byte-identical every rebuild
#     python3 -m evals.check_labels     # the labels, checked against the catalogue
#     python3 -m evals.baseline         # the free keyword router, 4 settings, 0 calls, $0.00
#
# ⚑ THE ABSENCE IS LOAD-BEARING ON THIS KIT IN PARTICULAR. Tool calling has a large framework
# industry attached to it -- LangChain, LlamaIndex, every provider's own agent SDK -- and any of
# them would out-engineer src/loop.py. That is the point. The loop is deliberately the smallest
# thing that asks, parses one line, calls a tool and asks again, so that what the eval measures is
# the MODEL'S choice of tools rather than a framework's retry, repair and re-prompt behaviour
# sitting invisibly between the two. Swapping in a real agent framework is a seam (src/loop.py) and
# a re-run, which is the experiment this kit is set up to make easy rather than the one it
# forecloses.
