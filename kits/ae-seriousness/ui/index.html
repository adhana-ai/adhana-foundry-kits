Classify an adverse event's seriousness and route the urgent cases

One case report, one model call, a field table — plus one flag computed afterwards, in pure code, from what the model extracted. Serious is a regulatory classification, not a description of how bad the event sounds: a “severe” headache that resolved at home is not serious, and a “mild” rash that led to a hospital admission is. This kit never files a report and never starts a reporting clock; it only routes a case towards a human case processor sooner.

The flag fires only when the case is both regulatorily serious and the reporter's own causality assessment is related or possibly-related. A serious case the reporter calls unrelated — a hospitalised patient hit by a car — is still a case; it just does not get the same urgency here. This threshold is this kit's own simplification, not a real pharmacovigilance program's reporting clock or regulatory deadline.
