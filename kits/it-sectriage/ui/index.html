Two alerts, one source IP. One incident, or two?

Every card below is one case window — 2 to 4 security alerts a SOC already bundled together because they happened close in time and/or share an entity. The job: call each alert true or false positive, decide which true positives are genuinely the SAME incident, and draft a containment recommendation for the named on-call analyst to approve — citing the indicator that actually justifies it. Nothing here ever executes containment.

Two failure modes are planted on purpose. A calmly-worded true-positive phishing report that a keyword scan waves through, and two unrelated alerts that merely share a network address getting merged into one false incident. Both are marked below.
