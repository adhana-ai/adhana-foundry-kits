Seed a new item's forecast from prior comparable items

One new-item setup request with no sales history, one model call. It decides which prior items in the same category are genuine comparables — matching on material, price tier, channel and season, allowing an adjacent price tier and the online-only channel family — and a deterministic calculator drafts the recommended starting forecast from the like-item set alone, never asked of the model. Three verdicts per candidate: LIKE_ITEM, NOT_LIKE_ITEM, and UNSURE. The third is the point: a candidate that could plausibly go either way is not a coin flip — it is excluded from the estimate and left for a person.

The items and requests are synthetic, generated at build time from a fixed seed — never written from memory.
