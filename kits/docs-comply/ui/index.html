Check a document against a rulebook

One document, one model call, a verdict per rule — with the line it relied on. Three verdicts: met, breached, and never addressed. The third is the point. Here silence is usually the finding itself — a required disclosure that was never made — and it must not collapse into "breached", because the remedies differ: one is a wrong statement to correct, the other a missing one to write.

The rulebook is transcribed from the eCFR at build time, never written from memory.
