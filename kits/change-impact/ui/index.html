Match a change request to the record it modifies

One message, one model call. It picks which candidate record (if any) the message is about, extracts the requested change, and a deterministic calculator turns that into a dollar impact and a date impact — never asked of the model. Three match outcomes: a specific record, NONE, and UNSURE. The third is the point: a message that could plausibly be about more than one record, with nothing in the text to settle it, is not a coin flip — it is a case for a person.

The records and correspondence are synthetic, generated at build time from a fixed seed — never written from memory.
