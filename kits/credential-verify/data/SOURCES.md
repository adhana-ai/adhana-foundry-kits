# Where this corpus came from

**It was written here.** `tools/build_corpus.py` generates every credentialing file from a fixed
seed (`SEED = 20260821`), so the corpus is byte-identical on every rebuild and there is no
third-party data in this kit at all.

| | |
|---|---|
| source | generated by `tools/build_corpus.py`, seed `20260821` |
| licence | **MIT** — this repository's own licence |
| files | 55, in `data/corpus/*.txt` |
| gold | 55 rows in `data/gold.jsonl` |
| providers | invented names, NPIs and license numbers, sampled without any link to a real person |

## Why an invented set of credentialing files, when real ones exist

**Because a real credentialing file is not something this repo can publish either.** It carries a
real provider's name, license number, NPI and — where an adverse action exists — sanction or
malpractice history: sensitive personal data tied to a real professional identity, held to the
same access discipline as PHI even though it is not itself a clinical record. There is no public
corpus of (credentialing file, credentialing-specialist-confirmed PSV outcome) pairs, for the same
reason no public corpus of bank statements or pay stubs exists.

**Nothing in here refers to a real person or licensing board.** Every name, NPI, license number
and PSV finding is invented; none states a real provider's actual status.

## The mechanic: one call per file, ten fields

Each file gives the model a provider/license header, a credentialing effective date, a PSV check
date and source, and the PSV finding text. The model extracts all ten fields, including whether
the finding describes any adverse action, however mildly worded. See `src/prompt.py`.

## The planted ambiguity: a mild word is still an adverse action

The eval this kit exists to run is whether a model catches an adverse action that reads as minor —
a "public reprimand," a "consent order," a "letter of concern" — or only flags the obviously severe
ones ("revoked," "suspended," "excluded"). `AMBIGUOUS_FRACTION = 0.40` of this corpus's adverse
findings are written in that mild, easy-to-dismiss phrasing, often paired with reassuring language
("license otherwise active and in good standing") in the same sentence. Gold always records
`sanction_or_adverse_action_found=yes` regardless of severity — a mild adverse action is still an
adverse action requiring committee review, per this kit's own facet sheet.

## Two more checks this kit's own facet sheet names, both pure code

Beyond the model's one judgment call, `src/extract.py::compute()` makes two further,
non-configurable checks directly from the extracted dates — no judgment involved, no model vote:

1. **License expired as of the credentialing effective date.** 8 of this corpus's 55 files carry a
   license that expired before the file's own effective date.
2. **PSV check outside the required lookback window.** `PSV_LOOKBACK_DAYS = 180` — this kit's own
   stated policy, not a real accreditation body's published standard (see README). 6 of this
   corpus's 55 files have a PSV check performed 200+ days before the effective date, well outside
   that window, even though the file otherwise looks complete.

`needs_review` fires whenever ANY of the three — expired license, stale PSV, or an adverse action
of any severity — is true. `evals/judge.py` reports recall on this combined flag as its own named
figure, never folded into a generic accuracy score.

## What it cannot tell you

⚠︎ **This kit reconciles and flags only — it never makes the credentialing determination.** Per
this kit's own facet sheet: "never makes the credentialing or network-participation determination
— reconciles the file and flags discrepancies for the credentialing committee/specialist to
decide." Every file with a stated adverse action, an expired license, or a stale PSV is routed to
a person; this kit never decides whether the provider is credentialed.

⚠︎ **`PSV_LOOKBACK_DAYS = 180` is this kit's own simplification.** Real credentialing standards
(42 CFR 438.214 for Medicaid managed care; separate NCQA/state standards for other segments) set
lookback windows that vary by segment and element — this kit applies one flat number, stated
plainly so nobody mistakes it for a specific accreditation body's actual published requirement.

⚠︎ **An invented corpus contains the ambiguity we thought to plant and no others.** A real
credentialing file carries confusions this one does not attempt — a name-variant mismatch between
the PSV record and the application (a maiden name, a suffix), a PSV source that itself returns a
stale or cached result, an adverse action reported by one state board but not queried because the
provider's other licenses were checked instead. A model that clears this corpus has cleared what
this corpus tests, not every way a real credentialing file can go wrong.
