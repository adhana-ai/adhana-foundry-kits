Flag a configured parameter that has drifted from reality

One parameter, one review call. It reads the configured value against a rolling window of what was actually observed — plus the trend and any outliers, computed by code — and decides FLAG (surface it for review, with a proposed corrected value attached) or HOLD. Decision-free by design: nothing here auto-applies a change.

The parameters and their windows are synthetic, generated at build time from a fixed seed — never written from memory.
