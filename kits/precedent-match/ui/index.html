Match a planned request to its prior comparable events

One planned request, one model call. It decides which prior events in the same category are genuine precedents — matching on mechanic, price band, ad placement and season, allowing an adjacent price band and the circular-placement family — and a deterministic calculator drafts the recommended lift from the analog set alone, never asked of the model. Three verdicts per candidate: ANALOG, NOT_ANALOG, and UNSURE. The third is the point: a candidate that could plausibly go either way is not a coin flip — it is excluded from the estimate and left for a person.

The events and requests are synthetic, generated at build time from a fixed seed — never written from memory.
