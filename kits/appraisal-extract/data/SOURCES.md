# Where this corpus came from

**It was written here.** `tools/build_corpus.py` generates every report from a fixed seed
(`SEED = 20260821`), so the corpus is byte-identical on every rebuild and there is no third-party
data in this kit at all.

| | |
|---|---|
| source | generated by `tools/build_corpus.py`, seed `20260821` |
| licence | **MIT** — this repository's own licence |
| reports | 55, in `data/corpus/*.txt` |
| gold | 55 rows in `data/gold.jsonl` |
| properties / appraisers | invented addresses and invented names, sampled without any link to a real property or person |

## Why an invented set of appraisal reports, when real ones exist

**Because a real appraisal report is not something this repo can publish either.** Appraisal
reports carry a real property address, a real licensed appraiser's name and a real client's loan
file — even where the raw report format is not itself a trade secret, publishing 55 of them would
publish 55 real addresses and real professional identities with no consent behind it. There is no
public corpus of (appraisal report, review-appraiser-confirmed structured record) pairs, for the
same reason no public corpus of bank statements or pay stubs exists.

**Nothing in here refers to a real property, appraiser or transaction.** Every address, name and
dollar figure is invented; none states a real appraisal.

## The mechanic: one call per report, ten fields

Each report gives the model a property/appraiser header, an effective and report date, the
valuation approach, the gross living area and comparable count, a Scope of Work section, a
Comments section, and — for reports that carry one — an extraordinary assumption. The model
extracts all ten fields, including whether an extraordinary assumption is stated ANYWHERE in the
report. See `src/prompt.py`.

## The planted ambiguity: a heading is not the only place to look

The eval this kit exists to run is whether a model reads the WHOLE report or only checks a
dedicated "Extraordinary Assumptions" section. `AMBIGUOUS_FRACTION = 0.40` of this corpus's
extraordinary assumptions are written with NO dedicated heading at all — embedded mid-paragraph in
the Scope of Work or Comments section instead, worded plainly, with nothing marking it as special.
The rest get a clearly labelled "Extraordinary Assumptions" section. Gold always records the TRUE
presence and verbatim text regardless of where it was placed — derived from which generator branch
produced it, never re-derived from a scorer's or a model's own reading of the section headings.

## The missed assumption is the safety-critical case

`extraordinary_assumption_present` is the field this kit's own facet sheet names as the point:
"catch... a missed extraordinary assumption... [which] changes whether the appraisal should be
relied on for the loan decision." A model that only checks the labelled heading will systematically
miss the 38% of this corpus's assumptions that are embedded elsewhere — exactly the failure mode a
naive keyword-and-heading extractor exhibits, and exactly what `evals/baseline.py`'s
heading-only floor demonstrates. `evals/judge.py` reports recall on this field as its own named
figure, never folded into a generic accuracy score.

## What it cannot tell you

⚠︎ **This kit extracts and structures only — it never judges USPAP compliance or accepts a
value.** Per this kit's own facet sheet: "extraction and structuring only — USPAP compliance
judgment and value acceptance stay with the certified review appraiser, never automated." Every
report with a stated extraordinary assumption is routed to a person; this kit never decides
whether that assumption is acceptable.

⚠︎ **This corpus assumes a text-extractable report.** A scanned, image-only appraisal report needs
OCR accuracy verified separately before extraction can be trusted — this kit has no OCR step and
was never tested against one.

⚠︎ **An invented corpus contains the ambiguity we thought to plant and no others.** A real report
carries confusions this one does not attempt — an assumption stated in an addendum the main body
only references, a hypothetical condition that reads almost identically to an extraordinary
assumption but is legally distinct, a reconciled value that changed between a draft and the final
report. A model that clears this corpus has cleared what this corpus tests, not every way a real
appraisal report can go wrong.
